# HanczFormation – GitHub Pages változat

Ez egy statikus, GitHub Pages-kompatibilis előnézeti csomag.

## Feltöltés
A ZIP tartalmát **nem a ZIP-et**, hanem a kicsomagolt fájlokat töltsd a repository gyökerébe:

- index.html
- style.css
- script.js
- assets/
- .nojekyll

Ezután GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

A várható cím:
`https://hanczformation.github.io/3d-webshop/`

## Megjegyzés
A kapcsolat/ajánlatkérő űrlap jelenleg bemutató módú, mert GitHub Pages önmagában nem futtat PHP-t. Később Formspree/Netlify/WordPress backendhez köthető.
